# Artículo 755
Dentro de las veinticuatro (24) horas siguientes a la contestación de la demanda, o cuando ésta no haya sido contestada en el término legal, el Juez señalará fecha y hora para que las partes comparezcan en audiencia pública, que se denomina de conciliación y se celebrará dentro de los dos (2) días siguientes, salvo el caso de que ya se hubiere intentado conforme a este Código.
