# Artículo 56
Indemnización por Calidad Técnica del Servicio. La indemnización por una deficiente Calidad Técnica del Servicio que la Empresa Distribuidora debe pagar a cada Usuario al final del período de control será calculada según la densidad de carga del alimentador al cual está conectado mediante la expresión siguiente:
Dónde: i.
Indemnización por pagar al Usuario u para el período de control (USD); ii.
Costo de la Energía no Suministrada (USD/kWh); iii.
Factor de indemnización del alimentador a para el período de control; iv.
Energía no Suministrada del Usuario u durante el período de control s calculada con base en el índice TIU (kWh); v.
Energía no Suministrada del Usuario u durante el período de control s calculada con base en el índice FIU (kWh).
El factor de indemnización se calcula mediante la expresión siguiente:
Donde: i.
Factor de indemnización del alimentador a para el período de control s; ii.
Factor de indemnización del alimentador a para el período de control s correspondiente al indicador de duración; iii.
Factor de indemnización del alimentador a para el período de control s correspondiente al indicador de frecuencia; iv.
Índice global real de duración del alimentador a para el período de control s; v.
Valor del sendero de calidad del indicador de duración para el alimentador a evaluado en el período de control s; vi.
Índice global real de frecuencia del alimentador a para el período de control s; vii.
Valor del sendero de calidad del indicador de frecuencia para el alimentador a evaluado en el período de control s.

Límite establecido para la tolerancia del índice FIU para el nivel de tensión y densidad de carga correspondiente; iv.
