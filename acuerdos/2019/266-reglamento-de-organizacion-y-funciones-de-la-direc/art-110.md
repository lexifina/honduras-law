# Artículo 110
Proceso de Reclutamiento y Selección. El proceso de reclutamiento y selección del personal de LA DIDADPOL está a cargo de la Unidad de Recursos Humanos, la cual se apoyará con el Centro de Evaluación de Pruebas de Confianza o la Superintendencia para la Aplicación de Pruebas de Evaluación de Confianza (SAPEC), para la certificación de confianza correspondiente, en base a Ley. Para este propósito, la Unidad de Recursos Humanos debe contar con el Manual o Protocolo correspondiente.
